日期：2026-10-11。只把可复现证据写为已验证；后续补入真实配置的服务名、模型 ID、日期与记录，不把配置开关当成能力探测成功。

| 对象            | 实现范围                                                             | 验证与限制                                                             |
| --------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 模型文本        | OpenAI-compatible Chat Completions，SSE、单选择、usage、流中断与超时 | 合成协议通过；至少两种真实配置仍未验证                                 |
| 模型工具        | 单个 function tool call、受控循环、授权后继续生成                    | 合成协议通过；并行调用/旧 function_call 不支持；真实模型工具行为待验   |
| 嵌入            | 可配置维度、版本化向量、失败时词项降级                               | 合成协议及权限通过；真实嵌入效果未验证                                 |
| 真实剧情效果    | 20 段三轮、每配置三次、人工四维评分                                  | 工具与固定语料已建立；尚无真实质量评分                                 |
| MCP             | Streamable HTTP、旧 HTTP+SSE；无认证/Bearer/受限 API-Key 头          | 合成服务；SDK 1.32.1，协议样本 2025-06-18/2024-11-05；真实远端服务待验 |
| MCP schema/权限 | 有限 schema 子集、按角色/世界授权、逐次审批、未知结果人工核对        | 详见 [P4 范围](p4-usage.md)；无 OAuth、STDIO、MCP Server、任意脚本     |
| 角色/世界书导入 | CC v2/v3 JSON/PNG 与声明的字段子集、原件与未知扩展保留               | 固定合成 fixtures；[字段限制](p3-usage.md)；不执行宏、脚本、远程资源   |
| Apple           | SwiftUI，iOS 18+/macOS 15+，Swift 工具 6.2+                          | 构建/模拟器证据与边界见 P6 报告；签名/真机不由构建推断                 |
| APNs            | 可选中继、iOS/macOS topic、sandbox/production、通用文案              | HTTP/2/JWT 模拟测试；真实 APNs/物理显示未验                            |
| PostgreSQL      | 17、pgvector 0.8.2、pg-boss 12.37.1                                  | 容器集成、迁移与隔离恢复；独立 Linux 磁盘故障待验                      |
| Docker          | Node 24.14.0 / npm 11.9.0；arm64/amd64 构建                          | Docker Desktop 环境；x86 仿真不作原生性能结论                          |
| REST            | `/v1`；capabilities 协商；OpenAPI 0.6.0                              | 不支持群聊/分页等必要能力的服务明确拒绝；新增字段省略保留旧值          |
| schema          | 001–006；P5 原有快照保留；P6 分块加速                                | 空库、重复/中断迁移、跨块读取与 P5 格式兼容测试                        |
| 归档            | owner archive 格式 1，最大 32 MiB；整库用离线备份                    | JSON 校验与真实隔离数据库恢复；没有公开 archive 导入端点               |

已知容量限制：整份快照仍会在创建时物化；Apple 缓存/记录集合仍全量载入；完整工具历史初始同步只取最近 100 条。后台预算保守预留不退款；服务重启不会撤销已发生的现实副作用。详情以阶段报告和操作文档为准。
