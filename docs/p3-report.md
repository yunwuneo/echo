## 可靠性与隐私

- 外部提取/嵌入均在数据库事务之外；任务先预留预算并持久持有租约，提交复查任务 token、有效期、世界 memory_epoch 和设置修订。旧任务不能覆盖纠正或恢复删除内容；失败不推进游标。保守估算预留不退款，实际 usage 另记。
- 权限先于词项/向量排序。来源交集为空的记忆仅主人可见；用户陈述、角色声称和冲突分别保存，不产生已确认世界事实。人工缩小可知角色时不能扩大原证据权限。
- 实际 prompt 消息与记忆证据形成来源依赖。遗忘排除原文与依赖消息的未来上下文/提取，清理派生记忆、向量与历史修订。原文擦除还清除依赖消息正文。失效旧 sync 事件、快照以及刚构建但尚未保存的旧快照，客户端从权威快照重建；离线设备要重连后才能清理。
- 自动记忆不会改变剧情修订，因此最后一轮重生成仍可进行；重生成同事务失效派生记忆并重建世界书提交状态。世界书计数不随预览、模型失败或同请求重试推进。
- 导入不发任何网络请求；原件完整保存，映射字段之外的内容不会得到额外提示词或工具权限。受限解压、PNG 校验和、输入尺寸和条目上限有测试。

复现命令见 [P3 使用说明](p3-usage.md)。固定 Node 验证镜像用 `docker build --target development -t echo2-server:p3-check .` 创建；上述 npm 检查在该镜像内运行。模拟器使用 `Companion-iOS` scheme、iPhone 17 Pro Max（`34F8DBDA-87C9-4518-960E-56D6A03321CB`）和 Debug 临时签名；其他机器应替换为其实际模拟器 UUID。测试服务仅绑定本机回环，数据库仅含合成数据。

## 未决与下一步

- 没有真实模型 Key，尚未做两家供应商提取/嵌入效果评估、100 条真实模型输出证据人工复核或 20 段剧情评分。
- 没有以大数据量实测 300 ms 检索目标；pgvector 使用权限过滤后的精确检索，重建每批一条，共用每日预算，容量与参数需要 T13 基准。
- P3 自动整理按世界明确开启；后台预算按 UTC 日期，统一自主总开关、类别、用户时区与无人回顾由下一阶段 T09/T10 接入。工具和自主剧情的首版范围保持不变。
- 源文件导出保持未知扩展，不是编辑后重新生成完整第三方卡片；头像安装、完整迁移/导出恢复仍按既定后续任务交付。
