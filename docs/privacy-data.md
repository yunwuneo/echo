# 数据流、保存与删除清单

此表描述 0.6.0 实现，不是替用户选定的法律声明或上架隐私政策。首版只有一个主人，可配对多台自己的设备。

| 数据                                     | 保存/接收位置                                              | 用途与边界                                                                                                                |
| ---------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 消息、角色、世界书、虚构身份、记忆与来源 | 自部署 PostgreSQL；已配对 Apple 的 SwiftData 缓存          | 服务端权威；角色输入按世界、房间与受众过滤；现实资料不隐式成为角色经历                                                    |
| 模型输入/可见工具结果                    | 用户选择的模型服务                                         | 仅当前获准上下文；第三方保留由其策略决定，本项目删除不能撤回已经发送的数据                                                |
| 模型/MCP Key                             | 自部署数据库 AES-GCM 密文；运行时服务器解密                | 支持客户端关闭时执行；不是服务器无法解密的端到端加密；不进普通读取、日志、owner archive                                   |
| 配对码/会话凭证                          | 服务器保存哈希；Apple Keychain 保存会话                    | 配对码短时一次性；撤销与刷新重放防护；切换 URL/instance/epoch/owner 隔离缓存和待发送                                      |
| 工具参数/结果、审批与副作用状态          | 自部署数据库；获准工具目标；必要结果送模型                 | 现实写入默认逐次批准；未知结果不透明重试；普通日志无完整返回                                                              |
| APNs token                               | Apple 系统/Keychain 中的中继票据；中继加密数据库接收 token | 用于路由；APNs token 与模型 Key 无关；App 不把聊天正文交给中继                                                            |
| 推送绑定和投递标识                       | 可选中继与 APNs                                            | 仅邀请/challenge、实例/epoch/设备/topic/环境、票据、随机投递与事件 ID、通用载荷；无角色名、正文、记忆、剧情摘要和模型 Key |
| 服务器与中继网络元数据                   | 连接对端与宿主基础设施                                     | 网络端点会看见来源地址、时间和 TLS/HTTP 元数据；不能将“无正文”称为“没有任何数据”                                          |
| 诊断与普通日志                           | 自部署宿主；用户主动导出的文件                             | 版本、迁移校验和、数量/状态/错误类别/心跳；默认不含正文、密钥、完整工具返回和隐藏推理                                     |
| owner archive 与数据库备份               | 用户选择的本地保存位置                                     | archive 有私人剧情但无应用凭据；整库备份含加密凭据，主密钥单独保管；不自动上传                                            |
| 评估与容量报告                           | 项目 `.local/`，默认不打包                                 | 仅合成剧情、可选真实模型对合成剧本的回复；无生产数据；可能有本地环境信息，分享前自行核对                                  |

同步事件保留七天，分页快照十分钟；消息和业务历史不随事件清理而删除。P6 快照分块与父快照同事务创建，随遗忘、恢复和过期清理级联移除。记忆遗忘/原文删除会清理依赖、向量和相关修订，并阻止迟到任务重新写回；已离线设备要重连后重建才能清除旧缓存。

旧备份、用户导出、已收到数据的第三方和尚未重连的设备不会被远程魔法擦除。恢复旧库时优先重放较新删除 ID 清单，默认停用自主与现实工具并换 epoch；没有较新清单时不能保证还原全部删除意图。备份保留期限和副本删除由部署者制定，中继票据期限、撤销与 unknown 行为见 [通知指南](notifications.md)。
