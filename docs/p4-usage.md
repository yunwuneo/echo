# P4 自主行动与外部工具

P4 新增 `004_autonomy_and_tools.sql`，需要 API、Worker 和 Apple 客户端一起升级。先备份数据库和主密钥；实际升级与恢复演练仍在 T12。此次没有修改真实业务数据库。

## 开关、调度与预算

「设置 → 自主总开关与预算」管理总开关、IANA 时区及后台预算；「管理世界 → 自主行动与限额」分别开启世界、记忆、主动联系、角色互动。升级后新增开关全部关闭。已有 P3 记忆整理开关保留，但必须同时开启总开关、世界和记忆类别才继续提取、索引或语义查询；关闭时聊天仍可用词项检索。

主动联系/互动选择一个现有房间，互动要求群聊。每次最多 3 条角色消息（也受房间上限约束）；主动联系一次一条、每天最多 3 次，角色互动每天最多 4 次，间隔至少 120 分钟。用户发消息后的 10 分钟暂不触发。安静时段默认 22:30–08:00，按设置时区；开始与结束相同表示无安静时段，允许单独开启安静时段角色互动。自动记忆不受安静时段影响。

Worker 每分钟扫描到期时间，规则通过后进入同一个持久 RunEngine，无需客户端在线。全实例最多一个未结束自主运行；用户命令优先于排队的自主运行，已开始的自主发言在一步结束后让出。服务停机后只评估一次当前机会，不补发全部错过的窗口。角色可输出 `<skip>` 放弃这次机会，不生成假消息或回顾；仍占用本次请求与触发额度。

总开关、世界和类别的修订同时在开始/提交核对。关闭后再开启也不会使旧结果恢复有效。停止后不会发布新剧情；已经发送的模型请求可能仍产生消耗，已发出的现实工具操作需查看执行记录。

默认后台预算为每天 20 次模型请求、100000 输入 token、10000 输出 token。实例、世界和类别请求上限共同生效；世界也有输入/输出上限。环境变量 `BACKGROUND_DAILY_REQUEST_LIMIT`、`BACKGROUND_DAILY_INPUT_LIMIT`、`BACKGROUND_DAILY_OUTPUT_LIMIT` 是管理员上限，界面不能越过。日期按 IANA 时区计算。每次模型请求（包括工具后的继续生成、失败重试、记忆与嵌入）先事务预留，实际 usage 独立记录；预留不退款，缺失 usage 记 unknown。纯 MCP 网络请求不占模型调用次数。

暂停、无可用房间和预算不足不会调用生成模型。预算不足的 run 保留错误状态，后续按下一调度窗口重新评估；记忆保留未处理游标并定期重新检查。前台文本请求沿用独立请求上限。当前不估算货币价格。

## MCP 配置与授权

1. 在模型连接中明确勾选「模型支持工具调用」。原有连接仍默认关闭；可新建相同供应商的工具模型连接，并在房间选择它。标志是用户声明，不代表真实供应商已通过能力探测。
2. 「设置 → MCP 连接与授权」新增远程地址、协议及认证；执行工具发现。凭据在服务器用 AES-GCM 加密，绑定 owner、连接 ID 和密钥版本，模型和普通读取接口没有凭据。
3. 为具体世界内角色授权一个工具，选择实际“读取/写入”影响、到期时间与固定资源参数。工具自己的 `readOnlyHint` 不会自动获得读取权限。
4. 在实例与该世界分别启用工具读取/写入开关。这些是独立权限；前台工具不要求开启后台自主总开关。后台工具还要满足自主总开关、世界/类别和预算。
5. 现实写入默认逐次批准。「工具审批与运行记录」显示工具名、角色、实际参数、期限与结果。批准绑定参数 hash、工具定义指纹、授权/连接/世界/自主设置修订。变化后旧批准不可用，应取消旧动作并重新提出。

长期写授权必须至少固定一个完全相等的顶层参数，例如 `{"calendar":"personal"}`；嵌套值也按规范化 JSON 完全相等比较。其他参数仍须满足工具 schema。授权期限最多一年，可以随时撤销。修改连接会撤销关联授权并清空发现结果，必须重新发现和授权。

等待审批释放世界租约，用户仍可聊天；世界内容变化可能使原审批过时。默认审批 24 小时过期。一次 run 最多调用 4 次工具，逐个执行，不支持模型并行 tool calls。外部请求最多 30 秒，运行活跃期限默认 120 秒，审批等待时间不计入活跃期限。工具定义在真正 dispatch 前再次在线发现核对。

请求发出前先持久保存 executing。写入发生后丢失响应、Worker 在 dispatch 边界崩溃、已发请求被取消时，保守记录 outcome_unknown；不会自动重发。请先在目标系统核对，再选择「已核实成功/未执行」。这是人工报告，不伪装成工具返回。已取消 run 可以记录核对结果，但不会因此恢复生成。没有通用撤销现实副作用的能力。

带工具步骤的聊天不能透明重生成。重启从持久步骤继续，已完成工具不会重放。工具返回只作为当前角色、当前发言的非可信工具消息；不会赋予权限。来源被遗忘/删除后，对应工具参数与结果清理，旧运行不能从工具 transcript 恢复遗忘信息；副作用状态元数据保留。

## MCP 兼容矩阵与网络边界

| 项目            | P4 范围                                                                                                                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| SDK             | 官方 `@modelcontextprotocol/sdk` 1.32.1；[固定版本源码](https://github.com/modelcontextprotocol/typescript-sdk/tree/v1.32.1)                                                         |
| 传输            | Streamable HTTP；显式选择的旧 HTTP+SSE，无自动降级                                                                                                                                   |
| 验证协议        | 合成 Streamable HTTP 2025-06-18、旧 SSE 2024-11-05；其他版本可由 SDK 协商但没有逐版实测声明                                                                                          |
| 认证            | 无认证、Bearer、自定义 X- 请求头或 Api-Key；无 OAuth 流程、无 STDIO                                                                                                                  |
| Schema          | object/array/string/integer/number/boolean/null、properties、required、additionalProperties 布尔值、items、enum、const、数值/长度/数组数量上下界；description/title/default 为元数据 |
| 不支持的 schema | `$ref`、pattern、format、组合 schema、额外约束等，发现可见但禁用调用，不能当作忽略这些限制后可执行                                                                                   |
| 发现/暴露限制   | 最多 4 页、128 个工具；单工具定义 16 KiB；同连接每个角色运行最多 32 个已授权工具，所有连接总计最多 64 个                                                                             |
| 参数/返回       | 参数 16 KiB；网络响应累计 1 MiB；只接受文本/结构化结果，返回按保守 UTF-8 字节估算最多约 4000 token（因此也小于 32 KiB），超限标截断                                                  |
| 未实现          | MCP Server、采样/提示/资源服务、下载返回媒体、通用工具服务进程管理                                                                                                                   |

默认只允许公共 HTTPS；内网按连接列出精确 IP（IPv4/IPv6），没有全局放行。HTTP 仅用于该连接明确列出的地址。无 CIDR 配置。link-local、云元数据地址、IPv4 映射 IPv6、组播等始终拒绝。每个请求重新解析并校验 DNS，网络连接使用本次校验的固定地址；所有重定向拒绝，旧 SSE 的 POST endpoint 必须同 origin，凭据不跨 origin。MCP URL 不接受查询参数认证，使用专用凭据字段。

## 离线回顾、同步与入口

「管理世界 → 离线回顾」按实际提交顺序列出自主角色发言、发言者、时间和未读标记，点击跳到房间原文。当前使用确定性摘录，不额外调用摘要模型。一次最多 100 条，支持分页和标记已读；无事件时为空。回顾只从仍有效的完成消息读取，来源失效、房间删除或遗忘后不再展示旧摘录。

总设置、世界策略、连接的非敏感信息、授权和最近工具记录进入服务器快照及增量同步。完整审批和工具调用记录留在数据库；活动 REST/初始同步显示最近 100 条，当前未提供历史活动分页。工具/自主界面仍需网络提交修改，缓存可离线查看。

新增 API：`/v1/autonomy`、`/v1/worlds/{id}/autonomy`、`/recaps`、`/recaps/read`、`/v1/background-usage`、`/v1/mcp/connections`、`/{id}/discover`、`/v1/tool-grants`、`/v1/tool-calls`、`/v1/approvals`、`/{id}/decision`。编辑配置使用 `If-Match`；批准接口不接受替换参数。OpenAPI 是 TypeBox 生成结果，两端不手写独立业务编排。

验证命令、实际结果与未验证项见 [P4 实施记录](p4-report.md)。真实模型/远程 MCP 服务兼容、长时间压力、真机与完整 Mac UI 验收尚待后续验证；通知中继不属于 P4。
